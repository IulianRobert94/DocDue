# DocDue — Store Metadata

The store texts live in `store-metadata/` — that folder is the single source of truth:

| File | What's in it |
|---|---|
| `store-metadata/description-ro.txt` | Romanian: name, subtitle, keywords, promotional text, Play short description, What's New, full description |
| `store-metadata/description-en.txt` | English: same fields |
| `store-metadata/review-notes.txt` | Notes for the App Store review team |

Character limits are written next to each field. App Store: name 30, subtitle 30, keywords 100, promotional text 170, What's New 4000, description 4000. Google Play: title 30, short description 80, release notes 500, full description 4000.
